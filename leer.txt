  ---
  Resumen del Sistema Completo:

  Backend (NestJS + Prisma)

  - 8 módulos: Auth, Usuarios, Empresas, Checklists, Inspecciones, Hallazgos, Acciones Correctivas, Dashboard, Reportes
  - Generación de PDFs con PDFKit
  - Seed con datos de demo

  Web (React + Vite + MUI)

  - 12 páginas completas con navegación
  - Dashboard con gráficos Recharts
  - PWA configurado

  Mobile (Expo + React Native)

  - 10 pantallas con Expo Router
  - Cámara y GPS integrados
  - SecureStore para tokens

  Docker & DevOps

  - docker-compose.yml - Producción
  - docker-compose.dev.yml - Desarrollo
  - Makefile - Comandos útiles

  ---
  Para iniciar el proyecto:

  # Desarrollo completo
  make setup

  # O manualmente:
  cd backend && npm install && npx prisma migrate dev && npx prisma db seed
  cd web && npm install
  cd mobile && npm install
