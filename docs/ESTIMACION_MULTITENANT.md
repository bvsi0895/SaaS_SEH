# Estimación de implementación multiempresa

Estimación orientativa para un desarrollador senior, sin deploy ni coordinación
de producto.

| Bloque | Estimación |
|---|---:|
| Prisma, migraciones aditivas y backfill | 3–4 días |
| Contexto tenant, guards y permisos | 3–4 días |
| Auth/JWT y selección de contexto | 2–3 días |
| Backend y OpenAPI | 4–6 días |
| Web | 4–6 días |
| Mobile | 2–4 días |
| Tests de aislamiento y regresión | 3–4 días |
| Documentación y demo | 1–2 días |
| **Total** | **22–33 días de trabajo** |

No incluye facturación, invitaciones por email, SSO ni operación productiva.
